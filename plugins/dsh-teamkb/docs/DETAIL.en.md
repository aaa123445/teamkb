# TeamKB Knowledge Base

Search categorized knowledge, guidelines, documents and knowledge links. Contribute verified solutions without Python, MCP or project initialization.

## Settings

Configure the server URL and personal API Key directly on this plugin detail page, then save. The teamkb row also has a configuration page. The default server is https://www.ljc.monster. An empty Key field preserves the saved credential; select the clear checkbox to remove it. TEAMKB_KEY in the host environment is also supported.

Contributions are disabled by default. Enable them with a writer Key to allow verified, reusable and redacted knowledge submissions, subject to server review.

## Verify and upgrade

After saving, start a new session and call kb_stats to test the connection. Saving alone does not test connectivity. Version 0.1.1 adds localized metadata, artwork, documentation and a direct bundle settings form. Restart Desktop or the Web service after upgrading, then refresh the browser. Install into the profile you actually use. Credentials belong to the host profile; use separate profiles for different users.

## Sidebar workbench / 侧栏工作台

Open TeamKB 知识库 from the sidebar for search, document reading, connection settings and call logs. 侧栏支持连接测试、分类查询、文档检索和续读、当前个人 Key 的调用日志分页与脱敏结果详情；点击连接配置可保存设置。
